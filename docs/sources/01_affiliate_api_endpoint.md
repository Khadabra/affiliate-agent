# SUMBER 01: ENDPOINT SHOPEE AFFILIATE OPEN API INDONESIA

- **Klaim yang Diperiksa:** Apakah endpoint resmi Shopee Affiliate Open API untuk Indonesia adalah `https://open-api.affiliate.shopee.co.id/graphql`?
- **Status Verifikasi:** `DOCUMENTATION_ONLY` (Belum dapat diverifikasi dari dokumentasi publik resmi tanpa login).
- **URL Sumber:** 
  1. Halaman Login Portal Afiliasi Resmi: `https://affiliate.shopee.co.id/`
  2. Dokumentasi Integrasi Eksternal: `https://help.affise.com/en/articles/shopee-affiliate-integration`
- **Tanggal Akses:** 2026-11-02
- **Kutipan Pendek (Maksimal 15 Kata):**
  > *"Regional endpoint for Indonesia affiliate integration uses open-api.affiliate.shopee.co.id with GraphQL"*
- **Catatan & Fakta Aktual:**
  Dokumentasi resmi Shopee Open Platform publik (`open.shopee.com`) hanya memuat API seller (AMS). Endpoint GraphQL afiliasi publisher dikelola di portal internal `affiliate.shopee.co.id` pada menu Open API yang memerlukan autentikasi login pengguna. Endpoint ini berstatus `DOCUMENTATION_ONLY` hingga pengguna login dan memeriksa menu Open API di dashboard akunnya.
